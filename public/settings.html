🎙️ Voice

Local mic transcription, so answering out loud counts as replying.

🎙️ Where speech comes from

Most setups use File — the LocalVocal OBS plugin writing captions to a file.

Why?

LocalVocal transcribes your mic entirely on your own PC. It's third-party — keep it updated to match your OBS version, since an outdated build can crash OBS (for example when switching Scene Collections). Engine mode is for a speech-to-text server you run yourself instead.

Where to read it
Engine mode

Only for a speech-to-text server you run on this PC. Loopback addresses only.

Why run one?

A speech-to-text server (whisper.cpp server, faster-whisper-server, WhisperLive) gives the cast what LocalVocal can't: voice-activity gating, so silence stops inventing filler, and a confidence score per line. Audio never leaves your machine. Lines the engine is less sure about than the minimum confidence are dropped instead of being answered — 0 keeps everything, and a line with no confidence reported is always kept.

💬 How the cast handles what you say

They speak up when you say a ghost's name or answer a question one of them asked.

Why?

Most of what you say isn't aimed at them, and answering all of it spends an API call after nearly every sentence — roughly double the cost on a talkative stream. Either way they read it: unanswered speech is still in the transcript the next scheduled message sees.

Drops invented filler like "Thanks for watching!" from the quiet between sentences.

Why?

In the quiet between sentences (breaths, keyboard, room tone) speech-to-text invents filler: "Thank you.", "Thanks for watching!", "please subscribe", words stuck on repeat. Left in, the cast replies to things you never said. Only a line that is entirely filler is dropped.

A word that sounds like a ghost, your channel or the game is rewritten to it.

Why?

Word fixes only cover manglings you've already seen; this catches the rest. It fires only on names of four letters or more that genuinely sound alike, so ordinary speech is left alone. Your own word fixes always win.

Faint 🎙 lines of your speech (and 🎧 party audio). Deck only, never on the overlay.

Why?

      👻 About Hype Ghost

      Version … · GitHub · Release notes · Report a problem

      What it is

      A local-only cast of simulated AI viewers that watches your stream and chats with you — so you practice talking to chat even when nobody is watching. Updates install automatically from GitHub Releases (toggle on the App tab).

      The honesty rules

      Every cast message is labeled 🤖 AI, and the overlay carries a permanent "simulated viewers, not real people" watermark — real viewers and VOD watchers are never misled. Nothing ever posts to your Twitch chat or affects stream metrics; all Twitch access is read-only.

      Privacy

      Stream screenshots and (if enabled) your mic transcript go to the brain you chose — the Anthropic API, or your own local/OpenAI-compatible endpoint — to write messages, and nowhere else. Speech-to-text runs entirely locally inside OBS. With Twitch features on and no app credentials, your (public) channel name is sent to DecAPI. The app's server binds to 127.0.0.1 only. Your API key is stored unencrypted in the config file below — treat that folder like a password.
