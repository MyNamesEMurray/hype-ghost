    What does this cost me?

    You pay Anthropic directly for what the cast says — roughly $0.20 per hour of streaming on the recommended model, and nothing while the app is paused. The deck shows a running total.

    How do I run this for free?

    Install Ollama and run ollama pull qwen2.5vl:7b: nothing leaves your PC, but the model shares your GPU with the game. Use a vision-capable model so the cast can see your stream.

    Let the cast see your stream.

    In OBS: Tools → WebSocket Server Settings → enable the server, then copy the password here.

    Why does Hype Ghost need OBS?

    It takes a small screenshot of your live scene every so often, so the cast reacts to what is actually on screen instead of talking into the void. The screenshots go to your brain provider and nowhere else.

    OBS closed right now? Skip it — the connection retries on its own.

    How do I set LocalVocal up?

    Install LocalVocal, add its filter to your mic, and point it at a file or an OBS text source — then name that file or source below. Keep the plugin updated to match your OBS version: an outdated build can crash OBS.
